# Zoha Fatima — Portfolio

A premium, interactive 3D developer portfolio showcasing full-stack web development, AI integration, and workflow automation projects.

**Live site:** [zoha-portfolio-tan.vercel.app](https://zoha-portfolio-tan.vercel.app/)

## About

This portfolio presents real client work — including a luxury e-commerce platform and a complete restaurant management system — alongside an interactive 3D technology showcase. Built with a minimal, editorial visual style and cinematic scroll-driven motion.

## Tech Stack

- **Framework:** React, TypeScript
- **Styling:** Tailwind CSS
- **3D & Animation:** Three.js, React Three Fiber, Framer Motion / GSAP
- **Deployment:** Vercel
- **Form Handling:** Web3Forms

## Features

- Interactive 3D technology constellation
- Scroll-driven cinematic project case studies
- Fully responsive across mobile, tablet, and desktop
- Contact form with direct email delivery
- Smooth, accessible motion with reduced-motion support

## Getting Started

Requires [Node.js](https://nodejs.org/) and npm (or use [nvm](https://github.com/nvm-sh/nvm) to manage versions).

\`\`\`bash
git clone https://github.com/ZohaFatima4747/zoha-s-digital-canvas.git
cd zoha-s-digital-canvas
npm i
npm run dev
\`\`\`

The site will be available locally at `http://localhost:5173` (or the port shown in your terminal).
